# 카피라이팅

## 목적
명확하고 설득력 있으며 행동을 유도하는 웹/상세페이지 카피를 작성한다. 홈페이지, 랜딩페이지, 가격 페이지, 제품 상세, 쿠팡 상세페이지 등에 적용한다.

## 초기 정보 수집 (카피 작성 전 확인)
1. **페이지 목적**: 페이지 유형과 원하는 핵심 액션(구매, 문의, 가입 등)
2. **대상 고객**: 문제, 구매 이의사항(objection), 고객이 실제로 쓰는 언어
3. **상품/오퍼**: 경쟁사 대비 차별점, 전환 결과(before/after), 증거(리뷰/데이터)
4. **맥락**: 트래픽 출처(쿠팡 검색/블로그 유입/광고), 방문자의 사전 지식 수준

## 핵심 원칙
- **메시지-마켓 핏이 최우선**: 명확한 포지셔닝과 카피는 전환율과 판매 주기에 직접 영향을 준다.
- **명확함 > 창의성**
- **이점(benefit) > 기능(feature)** — 기능을 나열하지 말고 고객에게 무엇이 달라지는지 말한다.
- **구체성 > 모호함** — 숫자, 기간, 구체적 결과로 표현한다.
- **고객 언어 > 기업 언어** — 사내 용어·과장된 마케팅 어휘 대신 고객이 실제로 쓰는 표현을 쓴다.
- **문체**: 단순하고 구체적으로, 능동태로, 자신감 있게, 보여주듯(showing) 정직하게 쓴다.

## 프로세스
1. 위 "초기 정보 수집" 항목을 먼저 확인한다 (정보가 없으면 사용자에게 되묻거나, 브랜드 컨텍스트에서 합리적으로 추론하되 [불확실] 표시)
2. 섹션별 구조를 잡는다 (헤드라인 → 서브헤드 → 핵심 이점 3개 내외 → 사회적 증명 → CTA)
3. 초안 작성 후 원칙 체크: 이점 중심인가? 구체적인가? 고객 언어인가?
4. 대안 2-3안을 준비한다 (톤/각도를 다르게)

## 산출물 형식
1. **페이지 카피** — 섹션별 구성 (헤드라인/서브헤드/본문/CTA 등 구조화된 형태)
2. **주석** — 각 섹션에서 왜 이 표현을 선택했는지, 어떤 원칙을 적용했는지
3. **대안** — 헤드라인 등 핵심 요소에 대해 2-3가지 옵션과 근거
4. **메타 콘텐츠** — 필요 시 페이지 제목, 메타 설명(SEO용)

## ACM 적용 노트
- 보조화구(젯소/바니시 등)는 AL(알파색채)과 동가격대이므로, 카피에서 기능 나열보다 **브랜드 신뢰 신호**(45년 이상 업력, 국내 제조, 실사용 후기)를 이점으로 재구성해 차별화한다.
- 쿠팡 상세페이지 카피는 검색 유입 특성상 첫 3줄 안에 핵심 이점과 구매 이유가 드러나야 한다.
- 그리다(페이스페인팅)는 B2C 직접판매 비중이 높으므로 보호자/키즈 시장 언어(안전성, 지속력, 지움 용이성)를 우선한다.
