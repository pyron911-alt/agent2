# 콘텐츠 전략

## 목적
콘텐츠를 제품처럼 취급해 검색 기반 트래픽, 권위성(authority), 리드 생성을 유도하는 전략을 수립한다.

## 사전 조사
- **비즈니스 맥락**: 회사, 타겟 고객, 주요 목표(매출/인지도/리드)
- **고객 리서치**: 구매 전 자주 하는 질문, 영업 과정에서 나오는 이의, 고객 문의(CS) 패턴
- **현황 파악**: 기존 블로그/유튜브 콘텐츠, 보유 리소스(제작 인력, 촬영 여건)
- **경쟁 분석**: 경쟁사(SH/AL 등) 콘텐츠와 공백(gap) 지점

## 핵심 프레임워크

### Searchable vs Shareable
- **Searchable(검색형)**: 기존 수요를 포착 — SEO 최적화, 사용법/비교 콘텐츠
- **Shareable(공유형)**: 수요를 창출 — 독창적 아이디어, 데이터, 스토리

### 캘린더 배분 (60/30/10)
- 60% 검색 기반 콘텐츠
- 30% 공유 중심 콘텐츠
- 10% 실험적 콘텐츠

### 콘텐츠 유형
- 검색형: 사용법(Use-case), Hub-Spoke 구조, 템플릿/가이드
- 공유형: 생각 리더십, 데이터 기반 콘텐츠, 전문가 인터뷰/좌담

### Create Once, Distribute Twice (ORB 퍼널)
하나의 주요 콘텐츠를 여러 채널에 맞게 재구성해 배포한다: Borrowed(외부 채널, SNS) → Rented(플랫폼, 유튜브) → Owned(자사몰/블로그)로 점진 전환.

## 아이디어 발굴 방법
- 키워드 데이터 분석
- 영업/CS 팀 인사이트
- 포럼/커뮤니티 리서치
- 경쟁사 콘텐츠 분석

## 우선순위 평가 기준 (가중치)
- 고객 영향 40%
- 마켓핏 30%
- 검색 잠재력 20%
- 리소스 요구량 10%

## 산출물 형식
1. **콘텐츠 기둥** 3-5개 + 하위 주제 클러스터
2. **우선순위 주제 리스트** (제목, 유형, 타겟 키워드, 선정 근거)
3. **주제 클러스터 맵** (콘텐츠 간 내부 링크/연계 구조)
4. **발행 캘린더** (기간별 배분, 60/30/10 원칙 반영)

## ACM 적용 노트
- 콘텐츠 기둥 후보: 아크릴/유화/수채화 물감 사용법(검색형), 보조화구(젯소/바니시) 활용 가이드(검색형), 작가/강사 인터뷰(공유형), ACM 3개 브랜드(그리다/노드/호작) 활용 콘텐츠(검색형+공유형 혼합)
- 미술교육 채널을 장악한 SH 대비, 공유형 콘텐츠(미술 강사/작가 스토리)로 커뮤니티 신뢰를 쌓는 전략이 상대적으로 비어있는 공백 지점이다.
- 60/30/10 배분 시 블로그는 검색형 비중을 높이고, 유튜브는 공유형 비중을 높이는 채널별 조정을 고려한다.
